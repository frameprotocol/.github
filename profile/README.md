  FRAME
  =====

FRAME is a universal runtime for structured systems. Everything it hosts is a
FRAME in a governed relationship graph. Clients project and submit Intents —
they do not own state.

Quick Start
-----------

* Report issues: https://github.com/frameprotocol/frame/issues
* Organization: https://github.com/frameprotocol
* Documentation: https://github.com/frameprotocol/docs
* Build and run: https://github.com/frameprotocol/frame
* Integrity check: ./tools/architecture-check.sh

  ```
  FRAME a substrate. Domain products (vehicles, weather stations, marketplaces,
  hardware demos, and similar) are built with FRAME in other repositories.
  ```
